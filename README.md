🚀 멀티 트랙 악보 메이커 (Multi-Score V2)

🎵 프로젝트 메모: 멀티 트랙 악보 메이커 (Multi-Score V2)



프로젝트 개요

목표: 기존 단일 오선지 악보 제작 도구를 확장하여 여러 줄(트랙)을 동시에 편집하고 관리할 수 있는

웹 애플리케이션 구현.

기반 기술: Vanilla JavaScript, jQuery, HTML5, CSS3 (Flexbox, Transform).

화면 규격: 1280px * 720px (고정 비율 및 자동 스케일링 적용).

주요 구현 기능

✅ UI/UX 프레임워크



자동 스케일링 (Smart Scaling): 어떤 해상도에서도 1280x720 작업 영역이 화면 중앙에 꽉 차게

보이도록 CSS transform: scale() 로직 구현.

CSS Reset & Border-box: 브라우저 간 일관된 디자인 유지를 위한 리셋 스타일 및 레이아웃 계산 최적화

적용.

트랙 관리: '줄 추가(+)' 및 '줄 삭제(-)' 기능을 통해 다중 오선지 트랙을 동적으로 생성/제거 가능.

✅ 악보 렌더링 및 에셋 최적화



SVG 기반 오선지: 원본 sheet.svg를 분석하여 정확히 1234px 너비로 배치.

클린 아이콘 시스템: 기존 버튼 배경이 포함된 SVG에서 배경을 제거한 순수 음표/쉼표

이미지(note_.svg, rest_.svg) 16종 자동 생성 및 적용.

툴바 현대화: 툴바 버튼에서 불필요한 테두리를 제거하고 아이콘 자체만 강조되는 깔끔한 인터페이스로

개선.

✅ 드래그 앤 드롭 시스템 (핵심 로직)



드래그 프리뷰: 음표를 잡으면 마우스 끝에 실제 배치될 음표 모양이 따라다님. 현재 스케일링 비율을

실시간 계산하여 드롭 전후의 크기를 100% 일치시킴.

정밀 스냅 (Snapping): 마우스를 놓는 순간 가장 가까운 오선지의 줄(Line) 또는 칸(Space)의 좌표로

음표가 자동 정렬됨.

음악 이론 로직 적용:대가 반전 (Stem Reverse): '시(B)' 음계 이상으로 올라가면 음표 머리 방향이 자동으로 아래로

반전됨.

쉼표 특수 정렬: 쉼표 타입은 오선지 중앙에 안정적으로 배치되도록 별도 스타일 적용.

✅ 시각적 피드백 (Interactive Feedback)



컨텍스트 스냅 가이드: 드래그 중에 마우스가 선 위에 있으면 '얇은 파란색 선', 칸 위에 있으면

'푸른색 블록'이 나타나 배치될 위치를 직관적으로 예고함.

영역 보호: 높은음자리표 영역과 악보 끝줄 영역에는 음표가 드롭되지 않도록 인터랙션 범위 제한.

기술적 세부 사항 (Reference)

Pitch Data: 오선지의 96px 높이를 기준으로 15단계의 음계 좌표(pitchData) 정의.

Scaling Factor: Math.min(windowWidth / 1280, windowHeight / 720) 공식을 통해 정비율 유지.

DOM Structure: jQuery를 활용한 동적 DOM 생성 및 이벤트 위임(Delegation) 방식으로 성능 최적화.

향후 로드맵 (Planned)

배치된 요소 이동/삭제: 이미 놓인 음표를 다시 드래그하여 위치를 바꾸거나 클릭하여 삭제하는 기능.

데이터 저장 및 불러오기: 악보 데이터를 JSON 형태로 로컬 스토리지 또는 파일로 저장.

오디오 엔진 연동: 트랙별 음표 데이터를 분석하여 실제 .wav 음원 재생 기능 구현.

🚀 향후 작업 로드맵 (Original vs. V2)



악보 편집 및 시퀀싱 로직 (Core Logic)

원본은 음표의 순서와 박자를 엄격하게 관리합니다.

박자 자동 정렬 (Auto-Layout): 마디 내에서 음표들이 겹치지 않고 박자(Beat) 순서대로 가로로 자동

배치되는 로직.

음표 수정 및 삭제:이미 배치된 음표를 다시 드래그하여 음높이 수정.

음표를 클릭하거나 툴바의 '지우개' 모드를 통해 개별/전체 삭제.

마디(Measure) 확장: 현재 고정된 4마디 외에 곡의 길이에 따라 마디를 추가하거나 제거하는 기능.

오디오 엔진 구현 (Audio & Playback)

원본의 가장 큰 특징인 '실제 소리 듣기' 기능을 멀티 트랙에 맞게 이식해야 합니다.

음원 리소스 매핑: media/audio/notes/ 폴더의 .wav 파일들을 각 음계(pitchIndex)와 음표

종류(duration)에 맞춰 매핑.

다중 트랙 재생 (Multi-Track Playback): 여러 줄의 악보를 동시에 읽어 들여 화음으로 재생하는 기능

(트랙 간 싱크 맞추기).

재생 컨트롤: 재생(Play), 일시정지(Pause), 정지(Stop) 기능 및 재생 시 현재 연주 중인 음표

강조(Highlight) 효과.

메타데이터 및 UI 상세 (UI/UX Details)

원본에 포함된 곡 정보 입력 기능을 현대적으로 구현합니다.

텍스트 입력 시스템:곡 제목, 작사/작곡자 이름 입력 필드.

노랫말(가사) 입력: 각 음표 하단에 가사를 입력할 수 있는 필드 추가 (원본 input-lyric 참고).

저장 및 내보내기:작성한 악보를 이미지(PNG/SVG)로 저장.

프로젝트 자체 데이터를 JSON으로 저장하여 '나중에 이어 만들기' 지원.

팝업 및 안내: 원본의 popup_alert, popup_info 등을 참고하여 올바르지 않은 박자 입력 시 경고 알림

구현.

V2 전용 차별화 기능 (V2 Exclusive)

멀티 트랙 버전만의 강점을 살리는 기능입니다.

트랙별 악기 설정: 각 줄마다 다른 음색(예: 트랙 1은 피아노, 트랙 2는 플루트 등)을 지정할 수 있는

기능.

트랙 믹서: 특정 트랙만 음소거(Mute)하거나 볼륨을 조절하는 간단한 믹싱 기능.

드래그 앤 드롭 UX 고도화: 툴바에서 가져오는 것뿐만 아니라, 오선지 내의 음표를 다른 트랙으로

복사/이동하는 기능.

오디오 리소스 이식 및 시스템 구축

리소스 이식: 원본 프로젝트의 음원(라3~라5, 박자별 .wav 파일) 120여 개와 쉼표 음원을

multi-score-jq로 모두 이식했습니다.

AudioManager 구현: 음원 파일을 비동기로 프리로드하고, 악보 데이터(음계/박자)를 실제 파일 경로와

매핑하여 소리를 출력하는 엔진을 구축했습니다.

전체 프리로드 및 로딩 화면: 앱 시작 시 모든 음원이 로드될 때까지 사용자를 안내하는 로딩

오버레이를 추가하여 실행 안정성을 확보했습니다.

정밀 오디오 스케줄러 전환 (핵심 엔진 업그레이드)

setTimeout → AudioContext 전환: 자바스크립트의 시간 오차 문제를 해결하기 위해 웹 오디오 API

하드웨어 클럭(currentTime) 기반의 정밀 스케줄러로 전면 개편했습니다.

Look-ahead 알고리즘: 연주 시 약 100ms 미래의 음표를 미리 예약하는 방식을 도입하여, 화면 부하와

상관없이 박자가 절대로 밀리지 않는 연주 성능을 구현했습니다.

백업 생성: 기존 로직은 만약을 대비해 main.backup.js에 안전하게 보관 중입니다.

시 음표를 클릭만 해도 즉시 삭제되며, 전용 커서와 하이라이트 효과를 추가했습니다.

전체 삭제 기능: 악보의 모든 내용을 한 번에 초기화할 수 있는 전체 삭제 기능을 추가했습니다. (실수

배치 로직 정밀화

실시간 박자 체크: 드래그 중 마디의 박자가 가득 찬 경우(4박자 초과), 프리뷰 이미지와 가이드라인을

자동으로 숨겨 배치가 불가능함을 직관적으로 알 수 있게 했습니다.

특수 음표 정렬: 온음표(ID 7)의 경우, 쉼표와 마찬가지로 오선지 중앙에 맞춰지도록 별도의 정렬

🚀 Multi-Score V2 (멀티 트랙 악보 메이커)
Multi-Score V2는 웹 브라우저 환경에서 여러 줄(트랙)의 악보를 동시에 편집하고 관리하며, 작성한 악보를 실제 음원으로 재생할 수 있는 다중 오선지 악보 제작 웹 애플리케이션입니다.

🛠 Tech Stack
Core: Vanilla JavaScript, jQuery

Markup & Style: HTML5, CSS3 (Flexbox, Transform), FontAwesome

Audio: Web Audio API (AudioContext)

✨ 핵심 기능 (Key Features)
🎼 1. 직관적인 악보 편집 시스템 (Drag & Drop)
정밀 스냅 (Snapping): 음표 드래그 시 가장 가까운 오선지의 줄(Line)이나 칸(Space)에 자동으로 정렬됩니다.

음악 이론 로직 자동화: '시(B)' 음계 이상 배치 시 음표 머리 방향(대가)이 자동으로 아래로 반전되며, 쉼표와 온음표는 오선지 중앙에 안정적으로 자동 배치됩니다.

편집 및 조작: 이미 배치된 음표를 다시 드래그하여 이동할 수 있으며, '지우개 모드'를 통해 클릭 한 번으로 손쉽게 삭제할 수 있습니다.

시각적 피드백: 드래그 중 배치될 위치를 얇은 파란색 선이나 블록으로 미리 보여주며, 마디의 박자가 꽉 차면 자동으로 가이드가 숨겨져 배치를 제한합니다.

🎧 2. 고정밀 오디오 재생 엔진
정밀 오디오 스케줄러: 기존 setTimeout의 시간 오차 한계를 극복하기 위해 Web Audio API와 Look-ahead 알고리즘을 도입하여 박자 밀림 없는 완벽한 재생 성능을 구현했습니다.

실시간 드래그 사운드: 음표를 오선지 위에서 드래그할 때 해당 위치의 음계를 실시간으로 재생합니다. (과부하 방지를 위한 50ms 스로틀링 적용)

시각적 동기화: 재생 중인 음표가 실제 음의 길이에 맞춰 개별적으로 하이라이트(빨간색)되며, 곡이 끝나면 컨트롤러가 자동으로 정지합니다.

💻 3. 반응형 멀티 트랙 UI
스마트 스케일링 (Smart Scaling): 화면 해상도에 상관없이 1280x720 고정 비율의 작업 영역이 화면 중앙에 꽉 차게 유지됩니다.

트랙 관리: 버튼 클릭으로 다중 오선지 트랙을 동적으로 추가 및 삭제할 수 있습니다.

현대적인 레이아웃: 직관적인 아이콘 중심의 툴바와 화면 하단에 플로팅 되는 재생 컨트롤 바를 적용하여 작업 공간의 효율성을 높였습니다.
