🚀 Multi-Score V2 (멀티 트랙 악보 메이커)

Multi-Score V2는 웹 브라우저 환경에서 여러 줄(트랙)의 악보를 동시에 편집하고 관리하며, 
작성한 악보를 실제 음원으로 재생할 수 있는 다중 오선지 악보 제작 웹 애플리케이션입니다.

🛠 Tech Stack
Core: Vanilla JavaScript, jQuery
Markup & Style: HTML5, CSS3 (Flexbox, Transform), FontAwesome
Audio: Web Audio API (AudioContext)

✨ 핵심 기능 (Key Features)
🎼 1. 직관적인 악보 편집 시스템 (Drag & Drop)
정밀 스냅 (Snapping): 음표 드래그 시 가장 가까운 오선지의 줄(Line)이나 칸(Space)에 자동으로 정렬됩니다.

음악 이론 로직 자동화: '시(B)' 음계 이상 배치 시 음표 머리 방향(대가)이 자동으로 아래로 반전되며, 쉼표와 온음표는 오선지 중앙에 안정적으로 자동 배치됩니다.

편집 및 조작: 이미 배치된 음표를 다시 드래그하여 이동할 수 있으며, '지우개 모드'를 통해 클릭 한 번으로 손쉽게 삭제할 수 있습니다.

시각적 피드백: 드래그 중 배치될 위치를 얇은 파란색 선이나 블록으로 미리 보여주며, 마디의 박자가 꽉 차면 자동으로 가이드가 숨겨져 배치를 제한합니다.

🎧 2. 고정밀 오디오 재생 엔진
정밀 오디오 스케줄러: 기존 setTimeout의 시간 오차 한계를 극복하기 위해 Web Audio API와 Look-ahead 알고리즘을 도입하여 박자 밀림 없는 완벽한 재생 성능을 구현했습니다.

실시간 드래그 사운드: 음표를 오선지 위에서 드래그할 때 해당 위치의 음계를 실시간으로 재생합니다. (과부하 방지를 위한 50ms 스로틀링 적용)

시각적 동기화: 재생 중인 음표가 실제 음의 길이에 맞춰 개별적으로 하이라이트(빨간색)되며, 곡이 끝나면 컨트롤러가 자동으로 정지합니다.
